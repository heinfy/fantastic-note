# 常见菜单贡献点分别是什么？

## 结论

菜单贡献点是 `contributes.menus` 的键，决定命令出现在哪一块界面。命令面板、编辑器右键、编辑器标题、视图标题、树节点右键是最常考的五个。

## 展开

| 贡献点 | 出现位置 |
| --- | --- |
| `commandPalette` | 命令面板 |
| `editor/context` | 编辑器右键 |
| `editor/title` | 编辑器标签栏右侧 |
| `editor/title/context` | 编辑器标题右键 |
| `view/title` | 侧边栏视图标题上的按钮 |
| `view/item/context` | 树节点右键 |
| `explorer/context` | 资源管理器右键 |
| `scm/title`、`scm/resourceGroup/context` | 源代码管理视图 |
| `touchBar` | macOS 触控条 |

视图按钮一定要加 `when`，至少锁住 `view == 你的视图id`，不然每个视图标题都会多出你的按钮。

树节点要用节点上的 `contextValue` 区分文件夹和文件，例如 `viewItem == folder`。

图标走 `icon`，可以是文件，也可以是 `$(zap)` 这种 Codicon。标题栏空间小，图标比长文字合适。

一个命令可以同时出现在多个贡献点，每处各写一条，`when` 和 `group` 可以不同。

## 容易讲错的点

- `view/title` 和 `view/item/context` 不是同一个地方。前者是整块视图的工具栏，后者是节点。
- 命令面板默认会收录 `contributes.commands`。想隐藏要显式给 `commandPalette` 写 `when: false`。
- 编辑器没有焦点时，`editor/context` 不会出现，资源管理器里的操作不要只挂在这里。
