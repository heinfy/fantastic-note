# 调试适配器协议（Debug Adapter Protocol，DAP）

编辑器和调试器之间的协议，角色和 LSP 类似：界面留在 VS Code，具体调试器跑在适配器里。

扩展用 `contributes.debuggers` 声明一种调试类型，用 `DebugAdapterDescriptorFactory` 说明适配器怎么启动：本地可执行文件、TCP 端口、命名管道，或进程内实现。

`DebugConfigurationProvider` 负责生成和补全 `launch.json`。激活上，轻量扩展可以用 `onDebug`，重的扩展用 `onDebugInitialConfigurations` 和 `onDebugResolve`，避免每次调试都提前加载。

参考：https://code.visualstudio.com/api/references/activation-events
