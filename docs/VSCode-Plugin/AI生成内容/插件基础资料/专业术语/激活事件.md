# 激活事件（Activation Event）

写在 `activationEvents` 里的声明，告诉 VS Code 何时加载扩展并调用 `activate`。在此之前扩展代码不会执行。

常见形式是 `onLanguage:python`、`onCommand:demo.hello`、`onView:demo.tree`、`workspaceContains:**/pom.xml`。`*` 表示启动即加载，官方不建议随意使用。`onStartupFinished` 在启动完成后再加载，不拖慢启动。

从 1.74 起，扩展自己贡献的命令、语言、视图等会隐式激活，对应事件可以不手写。

参考：https://code.visualstudio.com/api/references/activation-events
