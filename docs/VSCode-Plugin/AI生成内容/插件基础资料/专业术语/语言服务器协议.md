# 语言服务器协议（Language Server Protocol，LSP）

语言工具和编辑器之间的 JSON-RPC 协议。服务器在独立进程里做补全、诊断、定义等，编辑器侧用语言客户端翻译成 VS Code 的语言功能。

这样重计算不堵扩展宿主，一种服务器也能接到多个编辑器。轻量功能不必上 LSP，直接 `languages.registerXxxProvider` 即可。

文档同步分全量和增量。诊断可以由服务器推送，也可以由客户端按文档来拉。

参考：https://code.visualstudio.com/api/language-extensions/language-server-extension-guide
