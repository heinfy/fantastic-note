# 虚拟文档（TextDocumentContentProvider）

只读文本，没有对应的真实磁盘文件。用 `workspace.registerTextDocumentContentProvider(scheme, provider)` 注册。用户或 `openTextDocument` 打开该 scheme 时，编辑器调用 `provideTextDocumentContent(uri)` 要字符串。

内容变了就触发提供器上的 `onDidChange`，编辑器会重新来取。典型用途是把二进制、拉取的网页或生成结果显示成文本。

需要目录浏览和保存时，用 `FileSystemProvider`，而不是虚拟文档。

参考：https://code.visualstudio.com/api/references/vscode-api
