# Tuple 常用方法

> 类型基础介绍见 [Python 数据类型](../2.Python%20数据类型.md)。

元组是不可变类型，因此没有增删改的方法，只有两个查询方法：

| 方法 | 说明 | 示例 |
| --- | --- | --- |
| `index(x)` | 返回第一个等于 x 的元素下标 | `('a', 'b').index('b') → 1` |
| `count(x)` | 统计元素出现次数 | `(1, 1, 2).count(1) → 2` |

## 示例

```python
colors = ('red', 'green', 'blue', 'red')

print(colors.index('green'))  # 1
print(colors.count('red'))    # 2
```

## 注意事项

元组本身不可变，但如果元素是可变对象（如列表），该元素内部仍可修改：

```python
t = (1, [2, 3])
t[1].append(4)  # 合法，t 变为 (1, [2, 3, 4])
# t[0] = 99      # TypeError: 'tuple' object does not support item assignment
```

> 需要「可变的元组」时，直接使用 List 即可。
