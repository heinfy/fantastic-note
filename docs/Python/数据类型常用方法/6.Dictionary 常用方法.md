# Dictionary 常用方法

> 类型基础介绍见 [Python 数据类型](../2.Python%20数据类型.md)。

## 常用方法

| 方法 | 说明 | 示例 |
| --- | --- | --- |
| `get(k[, default])` | 安全取值，键不存在返回默认值（默认 None） | `person.get('phone', 'N/A')` |
| `keys()` / `values()` / `items()` | 所有键 / 所有值 / 所有键值对 | `dict_keys(['name', 'age'])` |
| `update(d)` | 批量更新（存在则覆盖，不存在则新增） | `person.update({'age': 32})` |
| `pop(k[, default])` | 删除键并返回对应的值 | `person.pop('city')` |
| `setdefault(k, v)` | 键不存在时才设置默认值 | `d.setdefault('a', []).append(1)` |
| `clear()` | 清空字典 | `person.clear() → {}` |

## 示例代码

```python
person = {'name': 'John', 'age': 30}

# 安全取值
print(person.get('email'))       # None
print(person.get('email', '-'))  # -

# 批量更新
person.update({'age': 31, 'city': 'New York'})

# pop 删除并返回
city = person.pop('city')        # 'New York'

# setdefault：常用于给键设置默认容器
groups = {}
groups.setdefault('admin', []).append('Alice')
groups.setdefault('admin', []).append('Bob')
print(groups)  # {'admin': ['Alice', 'Bob']}
```

## 遍历与推导式

```python
person = {'name': 'John', 'age': 31}

# 遍历键值对
for key, value in person.items():
    print(key, value)

# 字典推导式
squares = {x: x ** 2 for x in range(4)}  # {0: 0, 1: 1, 2: 4, 3: 9}

# 合并字典（Python 3.9+）
a = {'x': 1}
b = {'y': 2}
print(a | b)  # {'x': 1, 'y': 2}
```
