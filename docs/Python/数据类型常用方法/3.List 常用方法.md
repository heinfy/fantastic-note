# List 常用方法

> 类型基础介绍见 [Python 数据类型](../2.Python%20数据类型.md)。

## 常用方法

| 方法 | 说明 | 示例 |
| --- | --- | --- |
| `append(x)` | 末尾追加元素 | `[1].append(2) → [1, 2]` |
| `insert(i, x)` | 指定位置插入 | `[1, 3].insert(1, 2) → [1, 2, 3]` |
| `extend(iterable)` | 合并另一个序列 | `[1].extend([2, 3]) → [1, 2, 3]` |
| `remove(x)` | 删除第一个等于 x 的元素 | `[1, 2, 1].remove(1) → [2, 1]` |
| `pop([i])` | 移除并返回指定位置元素（默认末尾） | `[1, 2].pop() → 2` |
| `sort()` / `reverse()` | 原地排序 / 反转 | `[3, 1, 2].sort() → [1, 2, 3]` |
| `index(x)` / `count(x)` | 查找下标 / 统计次数 | `[1, 2, 2].count(2) → 2` |
| `copy()` | 浅拷贝 | `b = a.copy()` |
| `clear()` | 清空列表 | `a.clear() → []` |

## 增删改查示例

```python
fruits = ['apple', 'banana', 'cherry']

fruits.append('orange')        # 增：末尾追加
fruits.insert(1, 'grape')      # 增：在下标 1 处插入
fruits.remove('banana')        # 删：删除第一个匹配元素
last = fruits.pop()            # 删：移除并返回末尾元素
fruits[0] = 'kiwi'             # 改：按下标修改
print(fruits.index('cherry'))  # 查：返回下标

fruits.sort()                  # 原地排序
print(fruits)
```

## 列表推导式

```python
squares = [x ** 2 for x in range(5)]          # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]
```

> 提示：`+` 拼接列表会生成新列表；`append()`、`extend()` 是原地修改。
