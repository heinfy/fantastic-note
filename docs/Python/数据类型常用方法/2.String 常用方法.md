# String 常用方法

> 类型基础介绍见 [Python 数据类型](../2.Python%20数据类型.md)。

## 常用方法

| 方法 | 说明 | 示例 |
| --- | --- | --- |
| `upper()` / `lower()` | 转大写 / 转小写 | `'Py'.upper() → 'PY'` |
| `strip()` | 去除两端空白字符 | `' hi '.strip() → 'hi'` |
| `split(sep)` | 按分隔符拆分为列表 | `'a,b,c'.split(',') → ['a', 'b', 'c']` |
| `join(iterable)` | 用指定字符连接序列 | `'-'.join(['a', 'b']) → 'a-b'` |
| `find(sub)` | 查找子串，返回下标（找不到返回 -1） | `'abc'.find('b') → 1` |
| `replace(old, new)` | 替换子串 | `'a-b'.replace('-', '+') → 'a+b'` |
| `startswith()` / `endswith()` | 判断前缀 / 后缀 | `'a.py'.endswith('.py') → True` |
| `count(sub)` | 统计子串出现次数 | `'aaa'.count('a') → 3` |

> 字符串是不可变的：以上方法都不会修改原字符串，而是返回一个新字符串。

## 格式化字符串

```python
name, age = 'Alice', 18

# f-string（推荐，Python 3.6+）
print(f'{name} 今年 {age} 岁')

# format() 方法
print('{} 今年 {} 岁'.format(name, age))

# % 格式化（旧式）
print('%s 今年 %d 岁' % (name, age))
```

## 综合示例

```python
text = '  Hello, Python World  '

clean = text.strip()                        # 'Hello, Python World'
words = clean.split()                       # ['Hello,', 'Python', 'World']
lower = clean.lower()                       # 'hello, python world'
replaced = lower.replace('python', 'java')  # 'hello, java world'

print('-'.join(words))  # Hello,-Python-World
```

## 快速查看方法列表

```python
# 列出所有非魔法方法
str_methods = [method for method in dir(str) if not method.startswith('__')]
print("字符串方法列表:", str_methods)

# 输出某个方法的帮助
help(str.upper)  # 查看 upper() 的用法
```

这段代码使用了**列表推导式（List Comprehension）**来获取 Python 字符串类型（`str`）的所有**公开方法**，并过滤掉以双下划线 `__` 开头的**魔法方法（Magic Methods）**。
