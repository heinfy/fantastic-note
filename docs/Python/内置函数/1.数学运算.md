# 数学运算

常用的数学运算内置函数：

| 函数 | 说明 | 示例 |
| --- | --- | --- |
| `abs(x)` | 绝对值 | `abs(-5) → 5` |
| `max(...)` | 最大值，支持多个参数、可迭代对象和 `key` 参数 | `max(3, 7, 1) → 7` |
| `min(...)` | 最小值，用法同 `max` | `min([4, 2, 8]) → 2` |
| `sum(iterable[, start])` | 求和，可指定起始值 | `sum([1, 2, 3]) → 6` |
| `round(x[, n])` | 四舍五入保留 n 位小数 | `round(3.14159, 2) → 3.14` |
| `pow(x, y[, mod])` | 幂运算，第三个参数取模 | `pow(2, 10, 7) → 2` |
| `divmod(a, b)` | 同时返回商和余数 | `divmod(7, 3) → (2, 1)` |

## 示例

```python
print(abs(-5))             # 5
print(max(3, 7, 1))        # 7
print(min([4, 2, 8]))      # 2
print(sum([1, 2, 3], 10))  # 16，从 10 开始累加
print(round(3.14159, 2))   # 3.14
print(pow(2, 10))          # 1024
print(pow(2, 10, 7))       # 2，等价于 1024 % 7
print(divmod(7, 3))        # (2, 1)

# max/min 支持 key 参数，按规则取极值
students = [('Alice', 85), ('Bob', 92)]
print(max(students, key=lambda s: s[1]))  # ('Bob', 92)
```
