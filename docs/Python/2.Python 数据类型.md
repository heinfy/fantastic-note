## 标准数据类型

Python 中常见的数据类型有：

- Number（数字）：包括 int（整数）、float（浮点数）、bool（布尔）、complex（复数）
- String（字符串）
- List（列表）
- Tuple（元组）
- Set（集合）
- Dictionary（字典）

> 注意：bool 并不是独立的第七类，它是 int 的子类，属于 Number 的一种。

Python 的六个标准数据类型按**可变性**划分：

- **不可变数据**（3 个）：Number（数字）、String（字符串）、Tuple（元组）；
- **可变数据**（3 个）：List（列表）、Dictionary（字典）、Set（集合）。

此外还有 bytes（字节串，不可变）、bytearray（字节数组，可变）等二进制序列类型，用于处理字节数据。

> 各数据类型的常用方法已拆分为独立文档，见各节末尾的链接。

```python
# 数字类型
num_int = 42
num_float = 3.14159
num_complex = 1 + 2j

# 布尔类型
is_valid = True
is_finished = False

# 字符串
greeting = "Hello, World!"
multiline_str = """这是
多行
字符串"""

# 列表
fruits = ['apple', 'banana', 'cherry']

# 元组
colors = ('red', 'green', 'blue')

# 集合
unique_numbers = {1, 2, 3, 2, 1}  # 实际存储 {1, 2, 3}

# 字典
person = {
    'name': 'John',
    'age': 30,
    'city': 'New York'
}

# 打印示例
print("整数:", num_int)
print("浮点数:", num_float)
print("复数:", num_complex)
print("布尔值:", is_valid, is_finished)
print("字符串:", greeting)
print("多行字符串:", multiline_str)
print("列表:", fruits)
print("元组:", colors)
print("集合:", unique_numbers)
print("字典:", person)
```

### Number（数字）

Python 支持 int、float、bool、complex（复数）。

在 Python 3 中，bool 是 int 的子类，因此布尔值可以被看作整数来使用，其中 True 等价于 1。

```python
issubclass(bool, int) # True

True + 1 # 2
False + 1 # 1

True == 1 # True
False == 0 # True
```

> Python 3 的 int 没有长度限制（只受内存限制），不会像 C/Java 那样发生溢出。

内置的 type() 函数可以用来查询变量所指的对象类型。

```python
a, b, c, d = 20, 5.5, True, 4+3j
print(type(a), type(b), type(c), type(d))
# <class 'int'> <class 'float'> <class 'bool'> <class 'complex'>
```

此外还可以用 isinstance 来判断：

```python
a = 111
isinstance(a, int) # True
```

> 数字类型的数学运算、进制转换、位运算、高精度计算等常用方法，见 [Number 常用方法](./数据类型常用方法/1.Number%20常用方法.md)。

### String（字符串）

- Python 中单引号 `'` 和双引号 `"` 使用完全相同。
- 使用三引号（`'''` 或 `"""`）可以指定一个多行字符串。
- 转义符 `\`。
- 反斜杠可以用来转义，使用 r 可以让反斜杠不发生转义。如 `r"this is a line with \n"` 则 `\n` 会显示，并不是换行。
- 按字面意义级联字符串，如 `"this " "is " "string"` 会被自动转换为 this is string。
- 字符串可以用 `+` 运算符连接在一起，用 `*` 运算符重复。
- Python 中的字符串有两种索引方式，从左往右以 0 开始，从右往左以 -1 开始。
- Python 中的字符串不能改变。
- Python 没有单独的字符类型，一个字符就是长度为 1 的字符串。
- 字符串切片 str[start:end]，其中 start（包含）是切片开始的索引，end（不包含）是切片结束的索引。
- 字符串的切片可以加上步长参数 step，语法格式如下：str[start:end:step]

---

```python
#!/usr/bin/Python

s = '123456789'

print(s)                 # 输出字符串
print(s[0:-1])           # 输出第一个到倒数第二个的所有字符
print(s[0])              # 输出字符串第一个字符
print(s[2:5])            # 输出从第三个开始到第六个的字符（不包含）
print(s[2:])             # 输出从第三个开始后的所有字符
print(s[1:5:2])          # 输出从第二个开始到第五个且每隔一个的字符（步长为2）
print(s * 2)             # 输出字符串两次
print(s + '你好')         # 连接字符串

print('------------------------------')

print('hello\nrunoob')      # 使用反斜杠(\)+n转义特殊字符
print(r'hello\nrunoob')     # 在字符串前面添加一个 r，表示原始字符串，不会发生转义
```

> 这里用变量名 `s` 而不是 `str`，避免覆盖内置的 `str` 类型。

> 字符串的常用方法（大小写转换、拆分连接、查找替换、格式化等），见 [String 常用方法](./数据类型常用方法/2.String%20常用方法.md)。

### List（列表）

列表是**有序、可变**的序列，可以存放任意类型的元素，支持索引、切片、追加、删除等操作。

```python
# 创建列表
fruits = ['apple', 'banana', 'cherry']
mixed = [1, 'hello', True, 3.14, [1, 2]]  # 可以混合类型
empty = []

# 索引访问（和字符串规则一致，支持负索引）
print(fruits[0])     # apple
print(fruits[-1])    # cherry

# 切片
print(fruits[0:2])   # ['apple', 'banana']
print(fruits[::-1])  # ['cherry', 'banana', 'apple']，反转列表
```

> 列表的增删改查、排序、列表推导式等常用方法，见 [List 常用方法](./数据类型常用方法/3.List%20常用方法.md)。

### Tuple（元组）

元组是**有序、不可变**的序列，一旦创建就不能增删改元素，适合存放固定不变的数据。

```python
# 创建元组
colors = ('red', 'green', 'blue')
single = ('only',)  # 单元素元组必须带逗号，('only') 只是字符串
empty = ()
packed = 1, 2, 3    # 甚至可以不加括号

# 支持索引和切片，规则与列表一致
print(colors[0])    # red
print(colors[1:])   # ('green', 'blue')

# 解包（Unpacking）
r, g, b = colors
print(r, g, b)      # red green blue

# 不可变：修改会报错
# colors[0] = 'pink'  # TypeError: 'tuple' object does not support item assignment
```

> 元组只有 `index()`、`count()` 两个查询方法，见 [Tuple 常用方法](./数据类型常用方法/4.Tuple%20常用方法.md)。

### Set（集合）

集合是**无序、可变、元素唯一**的容器，底层基于哈希表实现，适合**去重**和**快速成员判断**。

```python
# 创建集合（自动去重）
unique_numbers = {1, 2, 3, 2, 1}  # 实际存储 {1, 2, 3}
from_list = set([1, 2, 2, 3])     # {1, 2, 3}
empty = set()                     # 空集合必须用 set()，{} 是空字典

# 成员判断，平均 O(1)
print(2 in unique_numbers)  # True
```

> 集合的增删方法、并交差等集合运算，见 [Set 常用方法](./数据类型常用方法/5.Set%20常用方法.md)。
>
> `frozenset` 是不可变版本的集合，因此可以作为字典的键，或放入其他集合中。

### Dictionary（字典）

字典是**可变的键值对映射**，键必须唯一且不可变（如 str、int、tuple），值可以是任意类型。Python 3.7+ 的字典**保持插入顺序**。

```python
# 创建字典
person = {
    'name': 'John',
    'age': 30,
    'city': 'New York'
}
empty = {}

# 读取：键不存在会报 KeyError
print(person['name'])  # John

# 新增 / 修改
person['email'] = 'john@example.com'
person['age'] = 31

# 删除
del person['email']

# 判断键是否存在
print('name' in person)  # True
```

> 字典的 `get()`、`pop()`、`update()`、`setdefault()` 等常用方法与遍历技巧，见 [Dictionary 常用方法](./数据类型常用方法/6.Dictionary%20常用方法.md)。

## 集合（Set）和列表（List）的区别

集合（Set）和列表（List）是 Python 中两种不同的数据结构，它们有以下主要区别：

| **特性**     | **列表（List）**                    | **集合（Set）**                          |
| ------------ | ----------------------------------- | ---------------------------------------- |
| **有序性**   | 有序，保持元素插入顺序              | 无序，不保证元素顺序                     |
| **可变性**   | 可变                                | 可变                                     |
| **重复元素** | 允许重复元素                        | 不允许重复元素（自动去重）               |
| **表示符号** | 使用方括号 `[]`                     | 使用花括号 `{}`（空集合用 `set()`）      |
| **索引访问** | 支持索引访问（如 `list[0]`）        | 不支持索引访问                           |
| **查找效率** | O(n)                                | O(1)（平均，基于哈希表实现）             |
| **常用方法** | append(), insert(), remove(), pop() | add(), remove(), union(), intersection() |
| **内存占用** | 较少                                | 较多（因为需要维护哈希表）               |
| **应用场景** | 需要保持顺序或允许重复时使用        | 需要快速查找或去重时使用                 |

## 六大标准类型速查表

| 类型       | 创建示例     | 有序       | 可变 | 允许重复   | 典型场景               |
| ---------- | ------------ | ---------- | ---- | ---------- | ---------------------- |
| Number     | `42`, `3.14` | —          | 否   | —          | 数值计算               |
| String     | `'hello'`    | 是         | 否   | 是         | 文本处理               |
| List       | `[1, 2, 3]`  | 是         | 是   | 是         | 有序、可变的元素集合   |
| Tuple      | `(1, 2, 3)`  | 是         | 否   | 是         | 固定数据、函数多返回值 |
| Set        | `{1, 2, 3}`  | 否         | 是   | 否（去重） | 去重、快速成员判断     |
| Dictionary | `{'a': 1}`   | 是（3.7+） | 是   | 键唯一     | 键值映射、JSON 数据    |

选型建议：

- 需要下标访问、允许重复 → **List**
- 数据固定不变 → **Tuple**
- 需要去重或快速判断成员 → **Set**
- 需要键值对映射 → **Dictionary**
