# Python 语法

## 标识符

- 第一个字符必须是字母或下划线 `_`
- 其他部分由字母、数字和下划线组成
- 标识符对大小写敏感
- 中文等非 ASCII 标识符也是允许的

## Python 保留字

```python
import keyword
print(keyword.kwlist)
# ['False', 'None', 'True', 'and', 'as', 'assert', 'break', 'class', 'continue',
#  'def', 'del', 'elif', 'else', 'except', 'finally', 'for', 'from', 'global',
#  'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 'not', 'or', 'pass',
#  'raise', 'return', 'try', 'while', 'with', 'yield']

# 判断某个词是否为保留字
keyword.iskeyword('if')  # True
```

## import 与 from...import

| 写法 | 说明 |
| --- | --- |
| `import somemodule` | 导入整个模块，使用时需要加模块名前缀 |
| `from somemodule import func` | 从模块导入特定成员，直接使用 |
| `from somemodule import func1, func2` | 导入多个成员 |
| `from somemodule import *` | 导入全部成员（不推荐，容易命名冲突） |

```python
import sys
print(sys.argv)  # 命令行参数
print(sys.path)  # 模块搜索路径

from sys import argv, path  # 导入特定成员，直接使用
print(path)
```

## isinstance 和 type

- `isinstance(obj, class_or_tuple)`：考虑继承关系，传入元组可以检查多个类型，推荐使用。
- `type(obj)`：严格返回对象的实际类型，不考虑继承。

```python
class Animal:
    pass

class Dog(Animal):
    pass

d = Dog()

print(isinstance(d, Dog))         # True
print(isinstance(d, Animal))      # True，Dog 是 Animal 的子类
print(isinstance(d, (Dog, str)))  # True，可检查多个类型

print(type(d) == Dog)             # True
print(type(d) == Animal)          # False，只认实际类型
```

> 优先使用 `isinstance`，除非需要精确匹配类型而不允许继承。
