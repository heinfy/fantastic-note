# 函数签名与类

函数类型描述参数和返回值；类类型描述实例成员，并可通过修饰符、继承和接口约束实现。

## 函数类型签名

函数声明、类型别名和带调用签名的接口都能描述函数类型：

```ts
function getNameLength(name: string): number {
  return name.length;
}

type Formatter = (name: string, age: number) => string;
const format: Formatter = (name, age) => `${name} (${age})`;

interface Logger {
  (message: string): void;
}
const log: Logger = message => console.log(message);
```

为变量标注函数类型后，参数类型可由上下文推断。可选参数、默认参数和剩余参数的写法如下：

```ts
function greet(name: string, title?: string): string {
  return `${title ?? ''} ${name}`.trim();
}

function multiply(value: number, factor = 2): number {
  return value * factor;
}

function sum(...values: number[]): number {
  return values.reduce((total, value) => total + value, 0);
}
```

## 函数重载

重载可以描述“不同参数对应不同返回类型”的关系：

```ts
function convert(value: number, asText: true): string;
function convert(value: number, asText?: false): number;
function convert(value: number, asText?: boolean): string | number {
  return asText ? String(value) : value;
}

const numericResult = convert(10); // number
const textResult = convert(10, true); // string
const unchangedResult = convert(10, false); // number
```

调用方只能使用重载签名，不能直接调用实现签名。实现签名必须兼容全部重载；如果返回类型不随参数变化，通常使用联合类型参数即可。

## 异步函数与 Generator

```ts
async function loadCount(): Promise<number> {
  return 1;
}

function* generate(): Generator<number, void, unknown> {
  yield 1;
}

async function* generateAsync(): AsyncGenerator<number, void, unknown> {
  yield 1;
}
```

`Generator<Yield, Return, Next>` 分别描述产出值、结束返回值和 `next()` 接收值的类型；异步生成器使用 `AsyncGenerator`。

## 类与成员修饰符

```ts
class Person {
  static species = 'human';

  constructor(
    public readonly id: number,
    private name: string,
    protected age: number,
  ) {}

  get displayName(): string {
    return this.name;
  }

  set displayName(value: string) {
    this.name = value;
  }

  introduce(): string {
    return `${this.name}, ${this.age}`;
  }
}

const person = new Person(1, 'Alice', 24);
person.displayName = 'Tom';
console.log(Person.species, person.introduce());
```

- `public`：成员默认可公开访问。
- `private`：仅在声明它的类内部访问。
- `protected`：在类内部及其子类中访问。
- `readonly`：禁止在初始化和构造函数之外重新赋值。
- `static`：成员属于类本身，通过 `Person.species` 访问。

构造函数参数前的修饰符会同时声明并初始化实例属性。TypeScript 的 `private` 主要提供类型检查；需要运行时私有字段时，可使用 JavaScript 的 `#name` 语法。

## 继承、接口实现与抽象类

```ts
interface Printable {
  print(): string;
}

abstract class Report implements Printable {
  abstract title: string;

  print(): string {
    return this.title;
  }
}

class DailyReport extends Report {
  title = 'Daily report';

  override print(): string {
    return `[Daily] ${super.print()}`;
  }
}
```

`extends` 继承实现，`implements` 只检查类是否满足接口结构，不会自动补充成员。抽象类不能直接实例化，子类需要实现其抽象成员；`override` 确保被覆盖的成员确实存在于基类中。
