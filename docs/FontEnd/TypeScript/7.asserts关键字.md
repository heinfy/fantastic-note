# asserts 断言函数与穷尽检查

断言函数在条件不满足时抛出异常，在正常返回后让 TypeScript 缩小类型。`asserts` 描述这个约定，实际校验仍由函数体完成。

## 条件断言：asserts condition

```ts
function assert(condition: unknown, message = 'Assertion failed'): asserts condition {
  if (!condition) {
    throw new Error(message);
  }
}

function getLength(value: string | null): number {
  assert(value !== null, 'Value is required');
  return value.length; // value 已缩小为 string
}
```

`asserts condition` 表示正常返回后，传入的条件为真。用 `value !== null` 可以保留空字符串；直接检查 `value` 的真值则也会排除空字符串。

## 类型断言函数：asserts value is Type

```ts
function assertIsString(value: unknown): asserts value is string {
  if (typeof value !== 'string') {
    throw new Error('Expected a string');
  }
}

function uppercase(value: unknown): string {
  assertIsString(value);
  return value.toUpperCase();
}
```

与 `value is string` 类型守卫相比，类型守卫返回布尔值，供分支判断；断言函数校验失败时中断执行，正常返回后缩小类型，不需要额外的 `if`。

## 验证 API 响应

```ts
interface User {
  id: number;
  name: string;
}

function assertIsUser(value: unknown): asserts value is User {
  if (
    typeof value !== 'object' ||
    value === null ||
    !('id' in value) ||
    typeof value.id !== 'number' ||
    !('name' in value) ||
    typeof value.name !== 'string'
  ) {
    throw new Error('Invalid user data');
  }
}

async function fetchUser(): Promise<User> {
  const response = await fetch('/api/user');
  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }

  const data: unknown = await response.json();
  assertIsUser(data);
  return data;
}
```

只检查 `id`、`name` 存在，不能保证它们分别为数字和字符串。编译器不会验证断言函数的实现是否满足其声明，空函数体也不会自动生成校验。

## never 与穷尽检查

`assertNever` 用来检查联合类型是否已处理完所有成员，它的返回类型应为 `never`。这是一种穷尽检查方式，不依赖 `asserts`：

```ts
type Shape =
  | { kind: 'circle'; radius: number }
  | { kind: 'square'; sideLength: number };

function assertNever(value: never): never {
  throw new Error(`Unexpected shape: ${JSON.stringify(value)}`);
}

function area(shape: Shape): number {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2;
    case 'square':
      return shape.sideLength ** 2;
    default:
      return assertNever(shape);
  }
}
```

若向 `Shape` 增加成员却漏掉对应分支，`shape` 就无法缩小为 `never`，调用 `assertNever(shape)` 会产生编译错误。

`as Type` 和非空断言 `!` 不执行检查；断言函数会执行函数体，并且校验失败时不能正常返回。
