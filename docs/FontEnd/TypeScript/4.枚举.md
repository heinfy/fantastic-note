# 枚举与字面量联合类型

枚举为一组相关常量提供名称。选择写法时，需要考虑是否需要运行时对象、反向查找以及构建工具的支持。

## 数字枚举

未显式赋值时，首个成员为 `0`，后续成员依次递增。

```ts
enum NumericDirection {
  Up,
  Down,
  Left,
  Right,
}

const direction: NumericDirection = NumericDirection.Up;
console.log(direction); // 0
console.log(NumericDirection[1]); // 'Down'
```

数字枚举通常会生成包含“名称 → 值”和“值 → 名称”的运行时对象，因此支持反向查找。

## 字符串枚举

```ts
enum StringDirection {
  Up = 'UP',
  Down = 'DOWN',
  Left = 'LEFT',
  Right = 'RIGHT',
}

type DirectionKeys = keyof typeof StringDirection;
// 'Up' | 'Down' | 'Left' | 'Right'
```

字符串枚举成员需要用字符串字面量或其他字符串枚举成员初始化。其值适合日志和序列化，但不生成数字枚举式的反向映射。

## const enum

```ts
const enum Size {
  Small = 1,
  Large = Small * 2,
}

const size = Size.Large; // 默认由 tsc 内联为 2
```

`const enum` 的成员只能使用常量枚举表达式，不能依赖运行时计算。默认情况下，`tsc` 会内联成员引用并移除枚举声明；开启 `preserveConstEnums` 等配置会改变输出行为。

它不能作为普通对象传给 `Object.keys()`。对外发布环境常量枚举还可能遇到 `isolatedModules`、依赖版本和不同转译工具的兼容问题，应结合实际工具链选择。

## 对象常量与联合类型

需要运行时常量，又不需要反向映射时，可以使用普通对象和 `as const`：

```ts
const Direction = {
  Up: 'UP',
  Down: 'DOWN',
  Left: 'LEFT',
  Right: 'RIGHT',
} as const;

type Direction = (typeof Direction)[keyof typeof Direction];
// 'UP' | 'DOWN' | 'LEFT' | 'RIGHT'

const move: Direction = Direction.Up;
```

`as const` 保留字面量类型，并在类型层面将属性标记为只读。编译后仍有普通对象，它不会自动冻结对象，也不是零运行时开销。

只需要类型约束时，可以直接使用字面量联合类型：

```ts
type Status = 'loading' | 'success' | 'error';
```

- 需要数字反向映射或配合现有枚举 API：使用 `enum`。
- 需要命名常量和对应的值类型：使用对象常量配合 `as const`。
- 只约束允许的值：使用字面量联合类型，不生成运行时代码。
