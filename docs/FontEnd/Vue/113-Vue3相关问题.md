# Vue 3 开发常见问题

本页保留组件实例、DOM 更新和插件接入示例；setup、Teleport 等基础用法通过链接查阅。

## 怎样获取组件实例？

```js
import { getCurrentInstance } from 'vue';

export default {
  setup(props, { emit }) {
    const instance = getCurrentInstance();
    console.log(instance?.appContext); // 用于检查内部上下文。
    return { submit: () => emit('submit', props.id) };
  },
  props: { id: Number },
  emits: ['submit']
};
```

`getCurrentInstance()` 返回内部组件实例，适合框架或库级需求。普通业务优先直接使用 props、emit、inject 和模板 ref，避免依赖 `instance.proxy` 等内部结构。访问子组件的方法见 [setup 的公开接口](003-setup.md)。

## 状态修改后怎样访问最新 DOM？

```vue
<script setup>
import { nextTick, ref } from 'vue';
const count = ref(0);
const output = ref(null);

async function increment() {
  count.value++;
  await nextTick();
  console.log(output.value.textContent);
}
</script>

<template>
  <button @click="increment">增加</button>
  <p ref="output">{{ count }}</p>
</template>
```

`nextTick()` 等待当前批次的 Vue DOM 更新，也支持回调形式。它不等待任意异步请求或浏览器绘制。

## 怎样安装应用插件？

```js
// MyPlugin.js
export default {
  install(app, options) {
    app.config.globalProperties.$myPluginMessage = options.message;
    app.provide('myPluginMessage', options.message);
  }
};
```

```js
// main.js
import { createApp } from 'vue';
import App from './App.vue';
import MyPlugin from './MyPlugin';

createApp(App).use(MyPlugin, { message: 'Hello' }).mount('#app');
```

选项式 API 可通过 `this.$myPluginMessage` 访问；TypeScript 项目需要扩展 `ComponentCustomProperties` 类型。组合式 API 可直接注入，减少对内部实例的依赖。

```vue
<script setup>
import { inject } from 'vue';
const message = inject('myPluginMessage', '');
</script>

<template>
  <p>{{ message }}</p>
</template>
```
