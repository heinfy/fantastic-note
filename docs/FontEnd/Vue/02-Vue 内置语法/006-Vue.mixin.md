# Vue 2：Vue.mixin

`Vue.mixin()` 注册全局混入，影响之后创建的所有组件实例，通常仅用于插件或必须统一注入的行为。

```js
Vue.mixin({
  created() {
    if (this.$options.trackCreation) console.log('组件已创建');
  }
});
```

混入的生命周期钩子与组件钩子都会执行，混入钩子先执行；数据和方法等选项按各自合并规则处理，容易出现来源不清和命名冲突。

只在某些组件中复用时，可使用局部 `mixins: [featureMixin]`。Vue 3 中的应用级对应方法为 `app.mixin()`，业务逻辑优先提取为 [组合函数](../01-Composables/001-认识组合函数.md)。

参考：[Vue 2 混入](https://v2.cn.vuejs.org/v2/guide/mixins.html)。
