# Vue 2：Vue.use

`Vue.use(plugin, options)` 安装插件，应在创建根实例前调用。Vue 3 对应 `app.use()`。

## 插件形式

```js
const plugin = {
  install(Vue, options) {
    Vue.prototype.$message = options.message;
  }
};
Vue.use(plugin, { message: 'Hello' });
```

插件也可以直接是函数，接收 Vue 构造器与附加参数。

## 安装机制

下面是说明安装逻辑的伪代码，省略了运行环境与参数检查。

```js
const installed = new Set();

function use(plugin, ...options) {
  if (installed.has(plugin)) return Vue;
  if (typeof plugin.install === 'function') plugin.install(Vue, ...options);
  else if (typeof plugin === 'function') plugin(Vue, ...options);
  installed.add(plugin);
  return Vue;
}
```

同一插件对象在同一 Vue 构造器上只安装一次，返回构造器以支持链式调用。Vue 3 的安装记录属于当前应用，见 [createApp](../001-createApp.md)。
