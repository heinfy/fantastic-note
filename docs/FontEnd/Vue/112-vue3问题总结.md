# Vue 2 / Vue 3 响应式与迁移问题

本页集中说明版本差异，ref 的实现与 API 用法见 [响应式基础](004-ref%20和%20reactive.md)。

## Object.defineProperty 的边界

它拦截单个已有属性的读取与赋值；对象新增、删除属性不会自动通知已定义的 setter，深层观察需要逐个处理嵌套属性。

它可以为数组索引定义 setter。Vue 2 没有逐个劫持所有数组索引，而是包装 `push`、`pop`、`shift`、`unshift`、`splice`、`sort`、`reverse` 等方法，因此直接索引赋值和修改 length 不会按该机制通知更新。

```js
const array = [1];
let value = array[0];
Object.defineProperty(array, '0', {
  get: () => value,
  set(nextValue) {
    value = nextValue;
    console.log('索引已修改');
  }
});
array[0] = 2; // 会调用 setter。
```

## Vue 2 中怎样更新数组与对象？

```js
Vue.set(list, index, nextItem);
list.splice(index, 1, nextItem);
list.splice(newLength); // 缩短数组。

Vue.set(state, 'newKey', value);
Vue.delete(state, 'oldKey');
```

预先在 data 中声明所需根属性。Vue 3 对象代理可观察属性增删、数组索引与 length 变化，不再需要 `Vue.set()` / `Vue.delete()`。

## Vue 3 的 ref 怎样处理不同类型？

基本类型由 `.value` 的 getter / setter 追踪；可代理对象还会转为 reactive，内部属性变化由该 Proxy 触发。

```js
const count = ref(0);
const state = ref({ count: 0 });
count.value++; // ref setter。
state.value.count++; // 对象属性的 Proxy setter。
state.value = { count: 2 }; // ref setter，替换整个对象。
```

## 常见迁移变化

- `new Vue()` → `createApp()`，全局注册从 `Vue` 构造器移到应用实例。
- Vue 3 保留选项式 API，并提供组合式 API 与 `<script setup>`。
- 组件默认 `v-model` 使用 `modelValue` 与 `update:modelValue`；`.sync` 改为带参数的 `v-model`。
- `beforeDestroy` / `destroyed` → `beforeUnmount` / `unmounted`。
- filters 移除，使用格式化函数或 computed。
- `$children` 移除；需要访问子组件时使用模板 ref 与公开接口。
- `v-if` 与 `v-for` 同节点的优先级变化，见 [面试题合集](111-面试题合集.md)。

## React 与 Vue 的区别

Vue 以模板和响应式依赖追踪为常见编写方式，React 通常使用 JSX 与显式状态更新；二者都遵循组件输入的单向数据流，不能把 Vue 概括为「所有数据都是双向流动」。详细对比统一放在 [React 与 Vue 对比](../React/01-React/002-React与Vue对比.md)。
