# Vue 面试题合集

本页保留原理类问题的简答；具体 API 用法通过专题链接查阅。涉及版本差异的结论分别标注 Vue 2 与 Vue 3。

## 1. 响应式与双向绑定有什么关系？

响应式负责从状态变化更新视图：Vue 2 主要用 `Object.defineProperty`，Vue 3 对象使用 `Proxy`，ref 使用 `.value` 的 getter / setter。双向绑定还需要视图到状态的输入事件。

```vue
<input :value="message" @input="message = $event.target.value" />
<!-- 文本输入场景可简写为： -->
<input v-model="message" />
```

组件上的 `v-model` 则关联模型 prop 与更新事件，见 [组件通信](04-Vue%20实践案例/005-组件通信.md)。

## 2. render 与 template 有什么关系？

`template` 是声明式模板，编译后生成 `render` 函数；`render` 返回 VNode，渲染器负责创建与更新真实 DOM。手写渲染函数适合需要灵活组合节点的场景。

```js
import { h } from 'vue';
const Greeting = { render: () => h('p', 'Hello') };
```

## 3. 模板怎样解析标签、指令与插值？

常规虚拟 DOM 编译流程为 `模板 → AST → 转换与优化 → 渲染函数`。元素、指令与插值先解析为节点，再转换为运行时可执行的代码；单文件组件通常在构建时完成编译。

运行时执行渲染函数生成 VNode，再通过 patch 更新真实 DOM。组件标签会解析到对应组件定义，而不是简单替换成 HTML 字符串。

## 4. KeepAlive 怎样缓存和刷新？

缓存组件实例与 VNode，切换时停用实例，再次进入时复用；通过组件名称限制范围，通过 `max` 控制容量。改变 key 可创建新实例，`$forceUpdate()` 不会重置缓存状态。详见 [路由组件缓存](03-Vue%20Router/02-keepAlive.md)。

## 5. v-for 的 key 有什么用？

key 帮助渲染器识别节点身份，决定复用、移动或重新创建，避免状态与内容错位。会插入、删除或排序的列表应优先使用稳定唯一 ID，避免使用数组索引。

## 6. v-for 与 v-if 谁优先？

同一节点上，Vue 2 的 `v-for` 优先，Vue 3 的 `v-if` 优先。Vue 3 的条件无法访问尚未建立的循环变量，建议先用 computed 筛选，或把条件放在外层。

```js
const activeUsers = computed(() => users.value.filter(user => user.active));
```

```vue
<li v-for="user in activeUsers" :key="user.id">{{ user.name }}</li>
```

## 7. 组件的 data 为什么是函数？

每个实例调用 `data()` 创建独立状态，避免组件实例共享同一个可变对象。Vue 2 的根实例可使用对象形式，但可复用组件需要函数形式。

## 8. hash 与 history 路由有什么区别？

hash 使用 URL 的 `#` 后部分，该片段不发送到服务器；history 使用 History API 改变路径，直接访问或刷新子路径时需要服务器回退到应用入口。详见 [前端路由模式](../JavaScript/013-前端路由模式.md)。

## 9. computed 与 watch 如何选择？

computed 表达同步派生值并按响应式依赖缓存；watch 执行请求、存储等副作用，支持新旧值与清理。只读 computed 不能赋值，可写 computed 的 setter 应更新源状态。见 [响应式基础](004-ref%20和%20reactive.md) 与 [侦听器](007-watch.md)。

## 10. 怎样监听页面滚动？

```js
import { onMounted, onUnmounted } from 'vue';

function onScroll() {
  console.log({
    top: window.scrollY,
    viewport: window.innerHeight,
    height: document.documentElement.scrollHeight
  });
}
onMounted(() => window.addEventListener('scroll', onScroll, { passive: true }));
onUnmounted(() => window.removeEventListener('scroll', onScroll));
```

在 setup 中注册钩子，确保事件监听成对清理；读取视口高度用 `innerHeight`，不是物理屏幕高度。

## 11. nextTick 等待什么？

等待 Vue 当前批次的 DOM 更新完成，用于修改状态后读取最新 DOM；不保证浏览器已经完成绘制。见 [开发常见问题](113-Vue3相关问题.md)。

## 12. Vue 2 为什么不能直接侦测数组索引赋值？

这是 Vue 2 数组观测实现的限制，不能归结为 JavaScript 无法对数组索引定义 setter。Vue 2 包装数组变更方法，索引替换用 `Vue.set()` 或 `splice()`，见 [响应式与迁移问题](112-vue3问题总结.md)。
