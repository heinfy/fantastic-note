# Vue 3 的事件绑定原理

Vue 的原生 DOM 事件最终使用 `addEventListener()`；组件自定义事件由 `emit()` 调用父组件传入的监听函数。

## DOM 事件的绑定与更新

```vue
<button @click.stop="handleClick">提交</button>
```

1. 模板编译把监听器转换为 VNode 属性，例如 `onClick`。
2. 渲染器的 `patchProp()` 将事件属性交给 `patchEvent()`。
3. 首次绑定时创建事件包装函数（invoker），再调用 `addEventListener()`。
4. 处理函数变化时通常更新 invoker 保存的函数引用，避免反复解绑、绑定。
5. 监听器被移除时调用 `removeEventListener()`。

## 事件修饰符

- `.once`、`.capture`、`.passive`：转换为原生监听器的 options。
- `.stop`、`.prevent`、`.self`：由包装函数在执行业务处理函数前检查或处理事件。
- 按键修饰符：检查键盘事件后再执行处理函数。

`.passive` 表示不会阻止默认行为，不应与 `.prevent` 一起使用。

## 组件自定义事件

```vue
<!-- Child.vue -->
<script setup>
const emit = defineEmits(['submit']);
</script>

<template>
  <button @click="emit('submit', { id: 1 })">提交</button>
</template>
```

```vue
<Child @submit="handleSubmit" />
```

组件事件不会像 DOM 事件那样向祖先冒泡。声明 `emits` 可区分组件事件与透传到根元素的监听器。通信示例见 [组件通信](04-Vue%20实践案例/005-组件通信.md)。

本文描述 Vue 3 常规虚拟 DOM 渲染路径。源码参考 [runtime-dom/events.ts](https://github.com/vuejs/core/blob/main/packages/runtime-dom/src/modules/events.ts)。
