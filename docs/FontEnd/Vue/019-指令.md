# 渲染控制指令

`v-pre`、`v-once`、`v-memo` 与 `v-cloak` 分别控制模板编译、一次渲染、子树缓存和挂载前的显示。

## v-pre：跳过编译

跳过当前元素及子元素的模板编译，适合显示原始插值文本。

```vue
<div v-pre>{{ message }}</div>
```

页面会直接显示 `{{ message }}`。

## v-once：只渲染一次

```vue
<p v-once>初始值：{{ count }}</p>
<p>当前值：{{ count }}</p>
```

第一段内容在后续状态变化时不再更新，适合固定的初始化快照。

## v-memo：按依赖缓存子树

Vue 3.2+ 支持，只有依赖数组中的值发生变化时才更新子树。用于 `v-for` 时必须放在同一个元素上。

```vue
<div
  v-for="item in list"
  :key="item.id"
  v-memo="[item.name, item.id === selectedId]"
>
  {{ item.name }} — {{ item.id === selectedId ? '已选中' : '未选中' }}
</div>
```

依赖数组必须覆盖子树需要更新的状态；遗漏依赖会导致旧内容一直显示。普通列表通常不需要 `v-memo`，先确认有性能问题再使用。

## v-cloak：隐藏尚未挂载的模板

主要用于直接在 HTML 中使用 Vue 的场景，需要配合 CSS。

```html
<style>
  [v-cloak] { display: none; }
</style>
<div id="app" v-cloak>{{ message }}</div>
```

挂载完成后 Vue 移除 `v-cloak`，内容恢复显示。单文件组件的模板已在构建时编译，通常无需此指令。

参考：[内置指令](https://cn.vuejs.org/api/built-in-directives.html)。Vue 2 自定义指令资料见 [Vue.directive](02-Vue%20内置语法/002-Vue.directive.md)。
