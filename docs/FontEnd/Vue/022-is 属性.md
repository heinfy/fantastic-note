# DOM 模板中的 is 属性

在直接使用浏览器 DOM 作为模板时，浏览器会先处理 HTML 嵌套规则，再交给 Vue 编译。自定义标签放在表格等容器中可能被移动到容器外。

## 表格中渲染组件

Vue 3.1+ 使用 `is="vue:组件名"`，保留合法 HTML 标签作为组件占位。

```html
<table>
  <tbody>
    <tr is="vue:my-row"></tr>
  </tbody>
</table>
```

```js
app.component('my-row', {
  template: '<tr><td>内容</td></tr>'
});
```

浏览器先看到合法的 `tr`，Vue 再在该位置渲染 `my-row` 组件。最终 DOM 由组件模板决定，不是强制保留原占位元素；在此场景中组件应输出合法的表格行结构。

## 使用边界

- `vue:` 前缀用于区分 Vue 组件与原生自定义内置元素的 `is` 属性。
- 主要用于 DOM 模板中的 `table`、`select` 等受 HTML 解析规则限制的容器。
- 单文件组件或字符串模板不经过浏览器的预解析，通常直接使用组件标签即可。
- 普通动态切换使用 [component 的 :is](021-component%20组件.md)。
