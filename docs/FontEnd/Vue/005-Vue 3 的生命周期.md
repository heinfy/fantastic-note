# Vue 3 的生命周期

组件经历创建、挂载、更新和卸载。组合式 API 在 `setup()` 中注册钩子；选项式 API 将钩子声明为组件选项。

## 常用钩子

- `onBeforeMount` / `beforeMount`：首次渲染即将开始，尚未创建组件 DOM。
- `onMounted` / `mounted`：组件 DOM 已创建，适合访问模板 ref、初始化第三方 DOM 库。
- `onBeforeUpdate` / `beforeUpdate`：状态已变，组件 DOM 更新前。
- `onUpdated` / `updated`：组件 DOM 更新后；等待某一次状态修改完成更适合用 `nextTick()`。
- `onBeforeUnmount` / `beforeUnmount`：卸载前，组件仍可用。
- `onUnmounted` / `unmounted`：组件卸载后，清理全局监听、定时器、连接等手动创建的资源。

`setup()` 在选项式 API 的 `beforeCreate`、`created` 之前运行；组合式 API 没有对应的创建钩子，初始化逻辑直接写在 `setup()` 中。Vue 2 的 `beforeDestroy`、`destroyed` 在 Vue 3 中改为 `beforeUnmount`、`unmounted`。

## 注册与清理示例

```vue
<script setup>
import { onMounted, onUnmounted, ref } from 'vue';

const width = ref(0);
const update = () => { width.value = window.innerWidth; };

onMounted(() => {
  update();
  window.addEventListener('resize', update);
});
onUnmounted(() => window.removeEventListener('resize', update));
</script>

<template>
  <p>窗口宽度：{{ width }}</p>
</template>
```

钩子通常应在 `setup()` 的同步执行期间注册。不要在 `setTimeout` 等异步回调中延迟注册。DOM 相关副作用放在挂载后，也能避免 SSR 时访问不存在的浏览器对象。

## 其他钩子与执行顺序

- `onActivated` / `onDeactivated`：用于 [KeepAlive 缓存组件](03-Vue%20Router/02-keepAlive.md) 的激活与停用。
- `onErrorCaptured`：捕获后代组件的错误。
- `onRenderTracked` / `onRenderTriggered`：开发模式下调试渲染依赖。
- `onServerPrefetch`：服务端渲染前等待异步数据。

常规流程为 `setup → beforeMount → mounted`，更新时为 `beforeUpdate → updated`，卸载时为 `beforeUnmount → unmounted`。同步子组件通常先于父组件完成挂载，父组件的更新后钩子在子组件之后执行。
