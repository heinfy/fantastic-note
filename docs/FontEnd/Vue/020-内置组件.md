# Vue 3 内置组件

内置组件处理过渡、缓存、DOM 挂载位置与异步依赖。模板中可直接使用，无需注册。

## Transition 与 TransitionGroup

`Transition` 为单个元素或组件添加进入、离开动画；`name` 指定过渡类名前缀，`mode="out-in"` 可先离开后进入。

```vue
<Transition name="fade">
  <p v-if="show">内容</p>
</Transition>
```

```css
.fade-enter-active,
.fade-leave-active { transition: opacity 0.3s; }
.fade-enter-from,
.fade-leave-to { opacity: 0; }
```

`TransitionGroup` 用于列表，各子项必须有唯一 key；Vue 3 默认不创建包裹元素，需要时用 `tag` 指定。

```vue
<TransitionGroup name="list" tag="ul">
  <li v-for="item in items" :key="item.id">{{ item.name }}</li>
</TransitionGroup>
```

列表移动过渡使用 `.list-move`。路由过渡见 [过渡动画](04-Vue%20实践案例/004-过渡动画.md)。

## KeepAlive

缓存动态组件实例，切换时停用而非立即卸载，可保留输入等组件状态。

```vue
<KeepAlive :max="10">
  <component :is="current" />
</KeepAlive>
```

`include` / `exclude` 按组件名称选择缓存范围，`max` 限制数量。缓存组件通过 `onActivated` / `onDeactivated` 处理启停；滚动位置等 DOM 状态可能需要自行保存。完整切换示例见 [动态组件](021-component%20组件.md)，路由集成见 [路由缓存](03-Vue%20Router/02-keepAlive.md)。

## Teleport

改变子节点的实际 DOM 挂载位置，逻辑上的组件父子关系、props 和依赖注入保持不变。常用于弹窗与浮层。

```vue
<script setup>
import { ref } from 'vue';
const open = ref(false);
</script>

<template>
  <button @click="open = true">打开弹窗</button>
  <Teleport to="body">
    <div v-if="open" class="modal">
      <button @click="open = false">关闭</button>
    </div>
  </Teleport>
</template>
```

`to` 指定目标选择器或 DOM 元素，目标通常需要在挂载时存在；`disabled` 可使内容留在原位置。

## Suspense

协调组件树中的异步 `setup()`（包括 `<script setup>` 顶层 `await`）与可挂起的异步组件，在等待时显示 fallback。

```vue
<!-- App.vue -->
<script setup>
import AsyncContent from './AsyncContent.vue';
</script>

<template>
  <Suspense>
    <AsyncContent />
    <template #fallback>加载中…</template>
  </Suspense>
</template>
```

```vue
<!-- AsyncContent.vue -->
<script setup>
const message = await new Promise(resolve => {
  setTimeout(() => resolve('加载完成'), 1000);
});
</script>

<template>
  <p>{{ message }}</p>
</template>
```

普通 `onMounted()` 请求不会自动成为 Suspense 的等待依赖。具体状态与限制见 [Suspense 文档](https://cn.vuejs.org/guide/built-ins/suspense.html)。
