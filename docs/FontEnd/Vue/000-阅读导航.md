# Vue 阅读导航

本目录按 Vue 3 基础 API、组合函数、路由与实践案例组织；「Vue 2 全局 API」保留旧项目维护资料，示例不可直接混用。

## 建议阅读顺序

1. 应用初始化：[createApp](001-createApp.md) → [mount](002-app%20的%20mount%20方法.md) → [setup](003-setup.md)。
2. 响应式基础：[ref、reactive 与 computed](004-ref%20和%20reactive.md) → [侦听器](007-watch.md) → [只读视图](008-readonly%20和%20shallowReadonly.md)。
3. 响应式工具：[值的判断与归一化](009-isRef、unref%20和%20toValue.md)、[属性引用](011-toRef%20和%20toRefs.md)、[浅层 ref](012-shallowRef、triggerRef%20和%20customRef.md)、[副作用作用域](015-effectScope、getCurrentScope%20和%20onScopeDispose.md)。
4. 组件能力：[生命周期](005-Vue%203%20的生命周期.md)、[依赖注入](016-provide%20和%20inject.md)、[内置组件](020-内置组件.md)、[动态组件](021-component%20组件.md)。
5. 逻辑复用与应用：[组合函数](01-Composables/001-认识组合函数.md)、[导航守卫](03-Vue%20Router/01-beforeRoute.md)、[实践案例](04-Vue%20实践案例/005-组件通信.md)。

## 版本说明

正文默认使用 Vue 3。`toValue`、getter 形式的 `toRef`、`hasInjectionContext` 需 Vue 3.3+；`defineModel`、`useModel` 需 Vue 3.4+；`useTemplateRef`、`useId`、`onWatcherCleanup` 需 Vue 3.5+。实践案例会单独标注 Vue 2、Vue CLI 或 Nuxt 2 等环境。
