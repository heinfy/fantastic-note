# 常见知识点

## CSS 实现骰子的"3"

```html
<div class="fa">
  <div class="son"></div>
  <div class="son"></div>
  <div class="son"></div>
</div>
```

```css
.fa {
  background-color: #fff;
  width: 100px;
  height: 100px;
  padding: 5px;
  border: 1px solid #f5f5f5;
  border-radius: 5px;
  display: flex;
  justify-content: space-between;
  align-items: flex-start;

.son {
  width: 20px;
  height: 20px;
  border-radius: 50%;
  border: 1px brown solid;
  background-color: brown;
  text-align: center;
  margin: 0 auto;
}
.fa .son:nth-child(2) {
  align-self: center;
}
.fa .son:nth-child(3) {
  align-self: flex-end;
}
```

## line-height 继承的坑

- 父元素 `line-height` 为 **px**：子元素继承的就是该 px 值；
- 父元素 `line-height` 为**倍数**：子元素的 `line-height` = 子元素自身 `font-size * 倍数`；
- 父元素 `line-height` 为 **%**：子元素的 `line-height` = 父元素 `font-size * %`（注意：是父元素的 font-size，且继承的是计算后的 px 值）。

## 实现 0.5px 边框

1. **伪元素 + `transform: scale(0.5)`**（推荐）：给容器设置绝对定位的伪元素，宽高为 200%、边框 1px，再用 `transform: scale(0.5)` 缩小一半，伪元素边框与容器边缘重合，视觉上宽度为 0.5px。兼容性最好，可一次性设置 4 个边框，且能正常展示圆角。
2. **伪元素 + 线性渐变**：给容器设置绝对定位伪元素，高度 1px，背景为线性渐变（一半有颜色、一半透明），视觉上宽度为 0.5px。适合设置单条边框，无法展示圆角。
3. **`box-shadow` 代替边框**：如 `box-shadow: 0 0 0 0.5px #000`，使用方便，能正常展示圆角，但兼容性一般。
4. **直接设置 `border-width: 0.5px`**：最简单，但兼容性不好（部分浏览器会按 0 或 1px 处理）。

## position: fixed 的定位参照

一提到 `position: fixed`，自然而然就会想到"相对于浏览器窗口定位"，但这并不准确：如果祖先元素设置了 `transform`，那么 `position: fixed` 的元素将**相对于该祖先元素**定位；否则才相对于浏览器窗口（视口）定位。

## 百分比的参照规则

### 宽高的百分比

**宽度和高度设置为百分数时，相对于父元素的宽度和高度来确定。**

- 子元素为浮动元素时，同样是相对于父元素的宽度和高度；
- 子元素为定位元素时，相对于其包含块（最近的外层定位元素）；如果祖先中没有定位元素，最终相对于 body 的宽度和高度。

当父元素的宽高受 `min-*` / `max-*` 限制时：

- `min-width` / `max-width`：父元素宽度受限时，子元素的百分比宽度仍可以正常解析（相对于父元素的宽度）。
- `min-height` / `max-height`：父元素高度受限时，子元素的百分比高度**无法**解析，相当于 `auto`。

### padding 与 margin 的百分比

**`padding` 和 `margin` 设置为百分比时，包括 `top` / `bottom` 在内的所有方向，都是相对于父元素的宽度来计算的**（即使父元素宽度本身是百分数也可以）。这与宽高百分比的参照规则不同，需要特别注意。
