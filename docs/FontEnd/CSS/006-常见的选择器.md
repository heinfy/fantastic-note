# 常见的选择器

## 结构与伪类选择器

- `>`：子元素选择器，选择指定元素的直接子元素。
- `:first-child`：选中某个元素的第一个子元素。
- `:last-child`：选中某个元素的最后一个子元素。
- `el:only-of-type`：匹配同胞中唯一该类型的元素；若存在多个同类元素则不匹配。
- `el:only-child`：匹配作为父元素唯一子元素的 `el`（父元素只有这一个子元素）。
- `el:first-of-type`：匹配同级中第一个该类型的元素。
- `el:last-of-type`：匹配同级中最后一个该类型的元素。
- `el:nth-child(n)`：匹配第 n 个子元素。
- `el:nth-of-type(n)`：匹配同级中第 n 个该类型的元素。
- `el + el`：相邻兄弟选择器，匹配紧随目标元素后的第一个元素。
- `el ~ el`：普通兄弟选择器，匹配目标元素之后的所有兄弟元素。
- `:link`、`:visited`、`:hover`、`:active`、`:focus`：伪类选择器。
- `ul li:not(:last-child)`：选择除了最后一个子元素以外的所有子元素。
- `::selection`：设置鼠标选中段落文字时的样式，如 `p::selection { ... }`。注意：该选择器中只能设置与颜色相关的属性。

## 属性选择器

| 选择器               | 说明                                                |
| -------------------- | --------------------------------------------------- |
| `E[attr]`            | 具有属性 `attr` 的元素，不限定属性值                |
| `E[attr="value"]`    | 属性值恰好为 `value` 的元素                         |
| `E[attr~="value"]`   | 属性值为空格分隔的列表，且其中包含独立 `value` 的元素 |
| `E[attr^="value"]`   | 属性值以 `value` 开头的元素                         |
| `E[attr$="value"]`   | 属性值以 `value` 结尾的元素                         |
| `E[attr*="value"]`   | 属性值中包含 `value` 的元素                         |
| `E[attr|="value"]`   | 属性值为 `value` 或以 `value-` 开头的元素           |
