# 浏览器本地存储

前端本地存储主要有以下几种方式：

1. **Cookie**：跨浏览器支持良好，可以存储少量数据（通常为 4KB），在客户端和服务器端都可以访问。缺点是存储容量有限，每次请求都会发送到服务器端，可能会影响性能；存在安全风险，如跨站脚本攻击（XSS）和跨站请求伪造（CSRF）。

2. **localStorage**：提供持久化的本地存储，数据不会过期，除非被显式删除。可以存储较大量的数据（通常为 5MB 或更大），存储和读取速度快，不会影响服务器负载。缺点是存储在客户端，无法跨域共享数据。

3. **sessionStorage**：提供会话级别的本地存储，数据只在会话期间有效，关闭标签页或浏览器后会被删除。适合临时存储数据。

4. **IndexedDB**：提供了较为强大和灵活的客户端存储解决方案，支持大容量数据存储和高性能检索，是一种 NoSQL 数据库，支持事务操作和索引查询。缺点是 API 相对复杂，使用上较为繁琐。

5. **Cache Storage（Cache API）**：提供了用于缓存 HTTP 响应的 API，可以用于存储离线应用所需的资源。通常通过 Service Worker 等技术来实现离线缓存。

Cookie 一般用于存储少量的客户端数据，通常用于实现以下功能：会话管理（记录用户登录状态）、用户偏好设置、跟踪和分析、广告投放、购物车状态、临时数据传输等。
