# 高阶组件（HOC）

**高阶组件（Higher-Order Component, HOC）** 是 React 中一种**复用组件逻辑的设计模式**，其本质是：

> **一个函数，接收一个组件作为参数，并返回一个新的增强组件。**

形式上类似于函数式编程中的高阶函数。

---

### 一、基本结构
```js
// 高阶组件（函数）
const withEnhancement = (WrappedComponent) => {
  // 返回一个新的组件
  return class EnhancedComponent extends React.Component {
    render() {
      // 可以注入 props、处理逻辑、拦截渲染等
      return <WrappedComponent {...this.props} extraProp="enhanced" />;
    }
  };
};

// 使用
const EnhancedButton = withEnhancement(Button);
```

> ✅ 核心：**不修改原组件，而是组合出新组件**（符合 React 的组合哲学）。

---

### 二、常见应用场景

#### ✅ 1. **注入 props（数据/方法）**
例如：从 Context 或全局状态中提取数据并传给子组件。
```js
const withUser = (WrappedComponent) => (props) => {
  const user = useAuth(); // 假设 useAuth 是自定义 Hook
  return <WrappedComponent {...props} user={user} />;
};
```

#### ✅ 2. **权限控制 / 条件渲染**
```js
const withAuth = (WrappedComponent) => (props) => {
  const { isAuthenticated } = useAuth();
  if (!isAuthenticated) return <Redirect to="/login" />;
  return <WrappedComponent {...props} />;
};
```

#### ✅ 3. **日志、埋点、性能监控**
```js
const withTracking = (WrappedComponent, eventName) => (props) => {
  useEffect(() => {
    trackPageView(eventName); // 上报埋点
  }, []);
  return <WrappedComponent {...props} />;
};
```

#### ✅ 4. **处理加载/错误状态（配合数据请求）**
> ⚠️ 注意：在 Hooks 时代，这类逻辑更推荐用自定义 Hook 实现。

```js
const withData = (url) => (WrappedComponent) => (props) => {
  const [data, setData] = useState(null);
  useEffect(() => {
    fetch(url).then(res => setData(res.json()));
  }, []);
  return data ? <WrappedComponent {...props} data={data} /> : <Loading />;
};
```

#### ✅ 5. **使用 `displayName` 便于调试**

```js
EnhancedComponent.displayName = `withHOC(${getDisplayName(WrappedComponent)})`;
```

---

### 总结

- **HOC 是函数 → 接收组件 → 返回增强组件**
- **用途**：逻辑复用、横切关注点（auth、log、data 等）
- **优势**：解耦、可组合
- **劣势**：嵌套复杂、props 传递不透明
- **现状**：**在 Hooks 时代已逐渐被自定义 Hook 取代**，但在某些场景（如需要修改渲染结构）仍有价值。

> 💡 **记住**：  
> **HOC 不是 API，而是一种设计模式。**
