JoyAgent-Work 是一款跨桌面与 Web 的 AI Agent 工作台，基于 Electron + Vue 3 开发，通过 SQLite 存储会话与记忆，支持 ACP 智能体、MCP 工具接入、定时任务与多进程架构，为用户提供本地化智能协作平台。

{/* truncate */}

1. 搭建奇点埋点：构建期注入 SDK，统一路由识别与上报封装，覆盖核心路径（Web/Electron）。
2. 发 AI 应用的连接器、专家、技能三大市场模块，覆盖分类筛选、搜索分页、一键安装启用、OAuth 授权、技能包上传分享等全流程功能。
3. 实现 Vite 后置 OSS 上传插件，构建完成即自动发布：按产物类型设置 CDN 缓存，上传失败阻断构建，一条命令完成打包与静态资源发布。
4. 实现桌面应用打包向导：分步选参、计划预览确认后执行，支持 dry-run/非交互，统一打包入口，降低误配风险。
